# Hi, I'm Naurder

I tend to learn by picking something slightly above my level and refusing to leave it alone until it starts making sense.

Most of what I build lives somewhere between **software, hardware, CAD and stubborn curiosity**. I’m less interested in collecting technologies for a list than in understanding a system well enough to make something real with it.

### A few things I've built or contributed to

- **[Interactive Fractal Generator](https://github.com/Naurder/Interactive-Fractal-Generator)** — a Python / PyQt5 desktop app for generating and exploring fractal trees in real time.
- **[Kalimba CAD Design](https://github.com/Naurder/Kalimba-CAD-Design)** — a complete conceptual instrument design with assembly, technical drawings, documentation and Blender visualizations.
- **[Apache Arrow](https://github.com/apache/arrow/pull/50153)** — a small C++ contribution to a very large codebase: missing `CTypeTraits` mappings for decimal types, compile-time tests, code review, CI debugging, and eventually a merge upstream.

Right now I’m learning **software engineering, embedded systems and open source** mostly the way I learn best: by building things before I fully know how to build them.
